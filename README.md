## 🌟 Executive Overview

This project is a high-fidelity modern redesign and full multi-page replication of **Shape Your Mind Consult** (`shapeurmind.org`). It preserves the authentic identity, clinical team, partner affiliations, phone numbers, and extracted imagery from the original website while elevating the user experience with modern healthcare design standards (inspired by modern digital health platforms like Headspace, Spring Health, and Modern Health).

## 🎨 Official Brand Design System & Color Palette

The color scheme is directly extracted from the organization's official emblem (the circular royal plum ring, golden bronze brain-tree, and open book):

- **Color Harmony:**
  - **Primary (Signature Royal Plum / Berry Wine):** `#80365d` (Light: `#9a4773`, Dark: `#581d3b`) — Extracted from the outer circular brand ring.
  - **Secondary (Warm Golden Bronze / Amber Oak):** `#b07d58` (Light: `#f8f3ee`, Dark: `#8c5d3a`) — Extracted from the growth brain/tree in the center.
  - **Accent (Vibrant Terracotta / Copper):** `#c85a32` (Hover: `#a8421d`) — High-impact booking and consultation triggers.
  - **Highlight (Golden Amber):** `#e09f67` — Pulse badges and accent subtitles.
  - **Neutral Canvas:** `#fdfbfb` (Warm soothing porcelain white) & `#f8f1f5` (soft plum surface).
  - **Dark Base / Midnight:** `#1f0e19` (Velvet plum-tinted midnight).
- **Typography:**
  - Modern Sans: `Plus Jakarta Sans`
  - Editorial Accents: `Playfair Display`
- **Iconography:** Lucide Icons (lightweight, vector SVG)

## Content management

Open https://www.shapeurmind.org/studio to manage published website content. The standalone editor is hosted at https://shapeurmind.sanity.studio and its source lives in studio/. Read studio/README.md for local development and studio/CONTENT-IMPORT.md for the initial content mapping. Publishing an entry updates the website through Sanity's public content API; no GitHub commit or manual redeployment is needed for content changes. Drafts remain visible only to authorized editors. Contact email settings change displayed links; form delivery routing is managed separately in Web3Forms.
